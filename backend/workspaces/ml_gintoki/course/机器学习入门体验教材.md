# 机器学习入门体验教材

## 课程概述

本教材为默认体验教材，面向机器学习零基础学习者。

通过苏格拉底式追问教学法，引导学生从直觉出发，逐步建立机器学习核心概念体系。

## 教材结构

本教材共 4 课时（V0.3 默认可见范围）：

1. **第 1 课：什么是机器学习** — 从人工规则转向数据驱动
2. **第 2 课：训练集与测试集** — 训练与评估分离，泛化能力
3. **第 3 课：线性回归** — 特征、参数与预测值
4. **第 4 课：损失函数** — 预测误差的衡量与优化目标

## 知识图谱概览

核心知识路径：

```
数据 -> 机器学习 -> 模型 -> 规律学习
训练集 -> 泛化能力 <- 测试集
过拟合 -> 泛化能力
特征 -> 线性回归 -> 预测值 <- 参数
预测值 -> 预测误差 <- 真实值
预测误差 -> 损失函数 -> 均方误差
```

## 教学原则

- 不直接给答案，用提问引导学生自己推导
- 每次只给一个核心结论，避免信息过载
- 学生卡住时拆分更小的问题
- 每节课紧密围绕一个核心概念
- 课后知识点自然串联形成局部知识图谱
